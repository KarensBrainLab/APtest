# Server_PHP

Deploy APtest to a PHP-capable web host. The default is **piano-only**; set `testMode: "both"` for the full manuscript protocol. The PHP endpoint stores summary CSV, trial CSV, and raw JSON **outside the public web directory** when correctly configured.
